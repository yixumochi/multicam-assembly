Methods / validation plan · not completed results

Check the operation, not the score

Sample across score bands [0.50,0.65), [0.65,0.70) and ≥0.70; include cases with and without drawings. Keep the sampling list separate from the two reviewers’ sheets. Each reviewer works independently, without consulting the cosine.

For each comparison inspect the source interval and annotate: same operation? same support condition? Use yes, no, or unclear. Cite an event/frame for each judgment; occlusion, missing drawings and uncalibrated views are reasons to use unclear. Record differences before resolution. Report sample size, coverage, agreement and unresolved items before making validation claims.
