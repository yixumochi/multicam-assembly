Source and implementation notes for the handoff snapshot

The module reuses analysis_v2/action_pairs_v2.csv, pair_dimensions.csv, and actions.csv as read-only inputs. The action-pair CSV was checked against the handoff SHA-256. The older text ablation output is stored under outputs/action_text_ablation_v1 and is outside this page's workflow.

In the handoff workspace, deliverable/build_research_module.py generated the overview, three comparison cards, and index.html. The case matrix replaced the count table. Side-by-side plots replaced the stacked charts and wheel explanation. Matrix cells list actions for the selected case pair and score band. A case number links to the corresponding case page.

The integration in the handoff workspace added a link from outputs/multicam_site/index.html to analysis/index.html. The existing three page labels kept their meaning. The color values came from the site's :root settings at the time: #12627d, #6ac2e7, #17363b, and #ee751c.

Example: Pair 107 reads row 107 from pair_dimensions.csv, with cosine 0.638 and raw angle changes of -6.2 and -6.1 degrees. The difference between their magnitudes is 0.1 degrees. card_107.svg also records the distinct starting angles of 16.9 and -54.1 degrees.
